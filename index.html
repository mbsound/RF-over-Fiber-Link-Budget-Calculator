Fiber Links

100%Signal flow — drag empty space to pan; ⌘/Ctrl + scroll to zoom. Drag a block to move it. Drag from a blue output dot (right side) to an input dot (left side) to connect. Drag an input dot into empty space to disconnect. Click a block to set it up. Numbers on the lines are the level of each carrier arriving there.

Gain ledger — every step from each transmitter to where it ends

“Per carrier” is one transmitter’s level. “Total” adds up every carrier present at that point in milliwatts (two 0 dBm carriers = 2 mW = +3.0 dBm).
